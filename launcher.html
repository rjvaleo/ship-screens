Bridge // Display Control

10 independently addressable panes · assign a data screen to each and deploy as its own window
Each slot opens its screen as a separate OS-level browser window (not a tab), so you can drag/resize/tile up to 10 of them across one or more monitors to build a full bridge console. Screens marked "pending" are not built yet — more will come online here as they're completed. For live microphone input and full audio features, serve this folder over a local web server (e.g. python3 -m http.server from this directory, then open http://localhost:8000/launcher.html) rather than double-clicking the file directly — browsers restrict microphone access on the file:// origin. Opened directly from disk, every screen still runs in full using its procedurally generated synthetic signal bed.
